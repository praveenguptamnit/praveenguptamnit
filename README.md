# Barber Appointment Registration + Admin Control

A lightweight single-page app for:

- Customers to register barber appointments.
- Admins to log in with a PIN and manage appointments.

## Features

- Appointment registration form.
- Admin login (`1234` by default).
- Admin dashboard listing all appointments.
- Mark appointments as completed.
- Delete a single appointment or clear all.
- Data persistence via browser `localStorage`.

## Run locally

One command:

```bash
./run.sh
```

Optional custom port:

```bash
./run.sh 9000
```

Then open `http://localhost:8000` (or your custom port) in your browser.
